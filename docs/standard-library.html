Seventeen core functions. Four explicit modules.

The prelude is available without imports. Statistics, text helpers, numeric helpers, and sourced quote constants live in registered, read-only module namespaces.

Implemented core, not a runnable CLI guide. These native functions and modules exist in the Go interpreter core. The approved language reference remains authoritative; a supported runner, checker, and REPL are not available yet. All snippets on this page are illustrative and have not been executed as CR7Script programs.

Core prelude: complete function surface

Signatures below describe positional arguments, not declaration syntax or type annotations. Only siuuu is variadic; every other function requires exactly the displayed number of arguments or raises AridadIncorrecta. Wrong argument types raise TipoIncorrecto. There are no implicit conversions, overloads, or spelling aliases, and core prelude names cannot be redeclared.

SignatureResult and contract
siuuu(value...)Display each value, separated by one space, then print a newline. Zero arguments prints a blank line. Returns nada; output failures raise EntradaSalida.
entrevista(prompt)Requires text. Prints the prompt without a newline, flushes, then reads one line. Strips one LF or CRLF, preserves other whitespace, and returns text. A final unterminated line is returned before subsequent EOF returns nada. An empty line is "", not EOF. Write, flush, or read failures raise EntradaSalida.
hala_madrid()Prints Uno, dos, tres... ¡Hala Madrid! followed by a newline. Returns nada; output failures raise EntradaSalida. This greeting is an adaptation, not the verbatim Q7 quote.
el_bicho(text)Returns locale-independent Unicode simple uppercase text, not locale-specific casing or multi-character expansion.
texto(value)Returns the stable display representation as text; see display rules.
numero(text)Explicit signed decimal conversion with surrounding ASCII whitespace allowed. Invalid syntax raises ConversionInvalida; a non-finite converted result raises NumeroNoFinito. See conversion details.
tipo(value)Returns a text label: numero, texto, booleano, nulo, lista, diccionario, funcion, modulo, or error.
palmares(value)Returns list length, dictionary key count, or text length as a number. Text counts Unicode scalar values, not UTF-8 bytes or grapheme clusters.
calma(ms)Blocks at least the given milliseconds, barring interruption, then returns nada. Requires a non-negative safe integer; negative, fractional, or unsafe values raise TipoIncorrecto.
rango(start,end)Returns a new list with inclusive start, exclusive end, and step 1. Both bounds must be safe integers with start <= end; otherwise raises RangoInvalido (non-numeric arguments raise TipoIncorrecto). Equal bounds return an empty list. Large ranges allocate memory.
chilena(list)Returns a new shallow reversed list. The original is unchanged; nested collection references retain identity. An empty list yields a new empty list.
hat_trick(value)Returns a new [value, value, value]. Reference values are repeated, not cloned.
convoca(list,value)Appends the value in place and returns nada. Aliases observe the mutation, even when the list is held by a leyenda binding.
banquillo(list)Removes and returns the last item in place. An empty list raises ListaVacia.
consulta(dict,key,fallback)Requires a dictionary and text key. Returns the stored value when present, including nada; otherwise returns the fallback. Does not insert the key.
contiene(collection,item)Returns a boolean: list membership using language equality, dictionary key presence (text item required), or text substring presence (text item required). Scalar equality compares values; collections, functions, modules, and errors compare by identity. An empty substring is present in any text.
exige(condition,message)Requires a boolean and text message. gol returns nada; fuera raises FaltaDelUsuario with the supplied message. Does not coerce truthiness.

A safe integer has no fractional part and lies between -9007199254740991 and 9007199254740991 inclusive. Numbers use finite IEEE-754 binary64; arithmetic is not exact financial arithmetic.

// Illustrative: shallow copies and shared references.
jugada comandante() {
    leyenda jugador = {"goles": 7};
    cantera equipo = hat_trick(jugador);
    jugador["goles"] = 8;
    exige(contiene(equipo, jugador), "Shared player expected");
    siuuu(chilena(rango(1, 4)));
}

Display is stable; conversion is explicit

siuuu and texto use the same deterministic display rules:

  • Booleans display as gol/fuera, null as nada, and top-level text without quotes.
  • Whole-valued numbers omit .0; negative zero displays as 0. Non-integral numbers use shortest round-trip decimal notation, with lowercase e when needed.
  • Lists and dictionaries use brackets and comma-space separators. Text elements are escaped and quoted; dictionaries retain insertion order.
  • A cycle on the current traversal stack displays as <ciclo>. Opaque values display as <funcion>, <modulo>, or <error CODE>.

numero accepts the decimal grammar [+-]?[0-9]+(\.[0-9]+)?([eE][+-]?[0-9]+)?, trimming only surrounding ASCII whitespace. Thus signed decimals and exponents are allowed, while .5, 1., 0x10, numeric separators, NaN, and Inf are not. Unicode whitespace is not silently trimmed. The library tests distinguish invalid conversion from overflow such as "1e999", which raises NumeroNoFinito.

Import one of four registered modules

The exact registered names are mr_champions, relato, marcador, and rueda_de_prensa. Imports precede other module declarations. Read exports through an alias; the alias is your choice, while export names are exact and case-sensitive. Module lookup does not download packages, perform resolution I/O, or print quotes. These modules expose no filesystem or network functions.

// Illustrative imports and calls; not an executed program.
fichar "mr_champions" como champions;
fichar "relato" como relato;
fichar "marcador" como marcador;
fichar "rueda_de_prensa" como frases;

jugada comandante() {
    siuuu(champions.soy_el_mejor([7, 10, 17]));
    siuuu(relato.une(["Hala", "Madrid"], " "));
    siuuu(marcador.redondea(-2.5));
    siuuu(frases.HALA_MADRID);
}

All module functions have fixed arity and strict argument types, using AridadIncorrecta and TipoIncorrecto as above. Namespaces are read-only. See modules and errors for initialization and recovery rules: runtime recovery neither rolls back effects nor retries automatically.

mr_champions: five statistics exports

The first four functions require a list containing only numbers. Arithmetic must remain finite or raises NumeroNoFinito. Sums are evaluated left to right; binary64 rounding and intermediate overflow also matter for the mean.

Export signatureContract
soy_el_mejor(numbers)Return the maximum number. Empty list raises ListaVacia.
minimo(numbers)Return the minimum number. Empty list raises ListaVacia.
goles_totales(numbers)Return the left-to-right sum. Empty list returns 0.
promedio(numbers)Return the arithmetic mean. Empty list raises ListaVacia.
pichichi(players)Require a non-empty list of dictionaries with numeric "goles". Return the original dictionary with the greatest score; the first wins ties. Empty list raises ListaVacia, missing key raises ClaveAusente, and invalid types raise TipoIncorrecto. Every player is validated, not only the winner; the result is not a copy.

relato: four text exports

Export signatureContract
minusculas(text)Return locale-independent Unicode simple lowercase text.
separa(text, separator)Return a list of texts, preserving empty fields, including leading/trailing fields. Empty input yields [""] with a valid separator.
une(texts, separator)Join a list of texts using the separator; every element must be text. An empty list returns "" with a valid separator.
reemplaza(text, old, replacement)Return text with all non-overlapping matches replaced. An empty replacement is allowed.

Separators in separa and une, and the search string old in reemplaza, must be non-empty text; an empty one raises TipoIncorrecto. These operations return new values rather than mutate their arguments.

marcador: three numeric exports

Export signatureContract
absoluto(number)Return the absolute value.
redondea(number)Round to the nearest integer, with halves away from zero: 2.5 rounds to 3 and -2.5 to -3.
potencia(base, exponent)Return numeric exponentiation. A non-finite result, including NaN from a negative base with a fractional exponent, raises NumeroNoFinito.

All arguments must be numbers; there is no automatic text-to-number conversion.

rueda_de_prensa: seven immutable text exports

The following are exact constant values, not functions or language keywords. Typographic outer quotation marks are not stored. Importing the module or reading a constant does not print it; call siuuu explicitly. Export identifiers are CR7Script adaptations, not identifiers used by Ronaldo. Football-inspired programming meanings are invented, and nicknames, gestures, and football terms are not quotations.
