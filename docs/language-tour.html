Guided tour · CR7Script 0.1

Learn the language one rule at a time.

CR7Script uses Spanish-first keywords and a football vocabulary. The language contract is intentionally strict: expressions have explicit types, names have lexical scope, and the evaluator does not guess what you meant.

Examples are illustrative. The approved language rules and interpreter core exist, but a supported runner, checker, and REPL are not available. Nothing on this page is a shell command or a claim that a CR7Script example was executed.

A program is built from declarations and blocks

A function declaration uses jugada; braces form a block; simple statements end with semicolons. The proposed entry function is named comandante(), but no current CLI invokes it.

jugada comandante() {
    cantera goles = 0;

    entrena goles < 3 {
        goles = goles + 1;
        siuuu("Gol", goles);
    }
}

Indentation is conventional rather than syntactic. The source contract uses UTF-8, case-sensitive identifiers, double-quoted strings, and // or non-nesting /* ... */ comments. There is no automatic semicolon insertion.

Values have explicit types

CR7Script is dynamically typed, but operations check their operands at runtime. Conditions require booleans; values are never treated as true or false just because they are non-empty or non-zero.

ValueLanguage formKey rule
Number7, 3.5Finite IEEE-754 binary64; integer precision is exact only through 253 − 1.
Text"Cristiano"Immutable Unicode text; length and indexing count Unicode scalar values.
Booleangol, fueraRequired for conditions and boolean operators.
NullnadaThe type label returned by tipo is nulo.
Collections[7, 10], {"goles": 3}Lists and string-key dictionaries are mutable references.
Other valuesFunctions, modules, errorsFunctions are first-class; imported namespaces and error fields are read-only.

Non-finite numeric literals are rejected during front-end analysis with NumeroNoFinito before program execution. Arithmetic results that are infinite or NaN also raise that code.

Bindings are mutable or non-reassignable

cantera goles = 0;
goles = goles + 1;

leyenda dorsal = 7;
// dorsal = 10;  // ReasignacionDeLeyenda

cantera creates a mutable binding. leyenda prevents rebinding that name; it does not freeze a list or dictionary stored in the binding. Assignment updates the nearest visible name and never creates a new variable.

leyenda plantilla = [7];
convoca(plantilla, 10);
cantera otra = plantilla;
otra[0] = 9;

Both names refer to the same list, so changing an element through otra is visible through plantilla. Same-scope redeclarations are errors; nested blocks may shadow outer names.

Operators have defined precedence

From higher to lower precedence, the core order is:

LevelOperatorsRule
Postfixf(...), x[i], m.nameCalls, indexing, and module/error property access.
Unary-, noNumeric negation; boolean NOT.
Multiplicative*, /, %Numbers only; division is floating-point.
Additive+, -+ accepts two numbers or two texts, not a mixed pair.
Relational<, <=, >, >=Compare numbers; chained comparisons are rejected.
Equality==, !=Equality follows type and identity rules.
Boolean ANDyShort-circuits and returns a boolean.
Boolean ORoShort-circuits and returns a boolean.
 
cantera listo = goles >= 3 y no lesionado;
cantera etiqueta = "CR" + texto(7);

Comparisons cannot be chained. Write 1 < x y x < 10. Assignment is a statement, not an expression; there is no ++ or += in 0.1.

Branches and loops use boolean conditions

si goles == 3 {
    siuuu("Hat-trick");
} sino {
    siuuu("Sigue entrenando");
}

si selects a branch; sino is optional. The condition must be a boolean. entrena repeats while its boolean condition is true.

temporada rival en ["Porto", "Juventus", "Barcelona"] {
    siuuu(rival);
}

temporada iterates lists in order, text as one-scalar strings, and dictionaries by insertion-ordered keys. It captures a shallow snapshot at loop entry. vestuario; and siguiente; break or continue the nearest loop; using either outside a loop is a resolver error.

Functions create lexical scopes

jugada rematar(potencia, precision) {
    devuelve potencia * precision;
}

Functions are first-class lexical closures and support recursion. Arguments evaluate from left to right; user-defined functions require their declared number of arguments (documented native functions may be variadic). Reaching the end of a function or using devuelve; produces nada.

Blocks create scopes. Parameters are mutable local bindings; reassignment does not rebind the caller's variable, while a passed list or dictionary keeps its reference identity. At module scope, functions initialize before constants; constants then initialize in source order.

Collections are mutable references

cantera plantilla = ["Cristiano", "Benzema", "Bale"];
plantilla[1] = "Marcelo";
convoca(plantilla, "Modrić");

cantera jugador = {"nombre": "Cristiano", "goles": 3};
jugador["goles"] = 4;
jugador["club"] = "Madrid";
  • List indexes start at 0; negative indexes are unsupported. Assigning at the list length does not append—use convoca.
  • Dictionary keys are text and preserve insertion order. Bracket access reads and updates fields; missing keys raise ClaveAusente.
  • palmares returns the length of text, a list, or a dictionary. consulta supplies a dictionary fallback, including when the stored value is nada.
  • Text cannot be assigned by index. Text indexing counts Unicode scalar values, not bytes or grapheme clusters.
