Getting started with CR7Script

Begin with the language contract, then explore syntax and library behavior. CR7Script is a language under active implementation, not a released command-line tool.

There is no supported runner yet. The project does not currently provide a `cr7script` executable, a syntax-check command, or a REPL. Do not expect the snippets on this site to run from a shell.

A recommended reading path

  1. Start with the language tour for guided syntax and core concepts.
  2. Read modules and errors for imports, initialization, and recovery.
  3. Browse the standard library guide for all native functions and modules.
  4. Apply the best practices and limitations when designing example programs.
  5. Use the language reference for exact semantics and edge cases.
  6. Review the architecture to understand the interpreter pipeline and implementation boundaries.
  7. Use the roadmap to distinguish implemented components from pending CLI work.

How to read examples

Code blocks are illustrative statements of the approved 0.1 contract unless a page explicitly identifies a tested Go-level example. They are not proof that a complete program has run. The proposed entry function is named comandante(), but no CLI currently invokes it.

jugada comandante() {
    leyenda dorsal = 7;
    siuuu("Siuuu", dorsal);
}

For contributors

The implementation uses Go 1.27 or newer and the Go standard library. From a checkout with the approved Go toolchain, the current repository checks are:

go test ./...
go vet ./...

These commands validate the Go implementation; they do not run CR7Script source files.
